Esta es la chuleta de los comandos de git
- `git diff`: lo que has cambiado y aún no has preparado
- `git diff --staged`: lo que ya está preparado
- `git log --oneline`: el historial, un commit por línea
- `git commit -am "mensaje"`: add y commit de lo ya seguido
- `git restore <fichero>`: descarta lo que no has guardado
- `git switch -c <rama>`: crea una rama
